# Project Milestone Workflow

Execute a structured, student-led project build.

## Step 1 — Problem Definition & Requirements
- Define the user stories, input/output contracts, and constraints.
- Verify student understanding of what needs to be built.

## Step 2 — Architecture & Data Structures
- Have the student design the classes, functions, and data flows.
- Discuss design trade-offs before writing code.

## Step 3 — Step-by-Step Implementation
- Break the build into small modules/milestones.
- The student writes the code; the AI acts as tutor and reviewer.
- Never write the whole project in one dump.

## Step 4 — Testing & Edge Cases
- Run the code.
- Test normal cases and deliberate malicious/edge inputs.
- Debug using the `/debug` workflow if errors occur.

## Step 5 — Code Review & Refactoring
- Run `/review` to classify fixes (Critical, Important, Improvement, Style).
- Refactor for clean architecture, readability, and performance.

## Step 6 — Active Recall Quiz & Mastery Check
- Quiz the student on why design decisions were made.
- Verify the student can explain every piece without notes.

## Step 7 — Update Roadmap
- Check off the project in `ROADMAP.md`.
- Move to the next milestone in the learning path.
