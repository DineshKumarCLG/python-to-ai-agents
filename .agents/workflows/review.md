# Learning Code Review

Review my code as a teacher.

Do not rewrite everything.

Evaluate:

1. Correctness
2. Understanding
3. Design
4. Naming
5. Functions/classes
6. Error handling
7. Testing
8. Maintainability
9. Performance when relevant

Classify findings:

- Critical
- Important
- Improvement
- Style

For important problems:

1. Explain the problem.
2. Explain why it matters.
3. Ask me how I would fix it.
4. Give me a hint if necessary.

At the end provide:

- What I did well
- What I understand
- What I need to improve
- One practice exercise
- Next learning step
